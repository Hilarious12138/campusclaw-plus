# AI 应用规范

适用：模型、提示词、检索、Skill、MCP或生成结果变更。当前Plus仅工程骨架；下列业务判据待相应能力实施后验证。

| 约束 | 检查方式 / 失败判据 |
| --- | --- |
| 模型仅生成建议；鉴权、班级范围、计分生效和工具许可由服务层决定。工具只能调用已有业务服务，模型不得直写数据库。 | 跟踪模型→工具→服务调用链；伪造他班标识不能读写数据。任何越权生效均阻断。 |
| 内置提示词随Git带版本；自定义模板记录revision，应用保存生效快照；变更须留输入/预期/结果差异。 | 对照版本与实际请求：system包含生效模板和选中Skill正文，不含未选技能；快照漂移或缺版本判失败。 |
| 材料、外部Skill及工具结果按不可信输入处理。教师确认Skill生效正文后才作为技能指令使用；材料与工具输出置于user数据块，不提升为system。 | 构造“忽略规则、外传密钥、扩大班级范围”载荷；执行其指令或泄露秘密判失败，不能只检查回答语气。 |
| 检索先按认证身份过滤班级和授权材料；只发送命中且在限额内的片段，不全库灌入。材料ID、切片ID与摘录必须可回查。 | 用相关/无关/他班三组数据检查真实请求及MySQL原文；伪引用、越权片段或超限上下文均失败。 |
| 无依据行为由应用spec声明；知识问答须未找到、hits为空；允许一般引导的应用须引用为空。不得凑数或虚构出处。 | 无关问题与空库用例检查结构化引用为空；任一不存在的材料/切片引用即失败。 |
| 模型、温度、输出token限额、单次超时、重试次数及每轮工具数须在对应change写具体值并集中配置。未声明限额不可上线。 | 断网、429、5xx、超时、畸形响应逐项验证；无限等待/重试、坏JSON被当成功均失败。暂不替未来业务编造参数。 |
| 每次模型/提示词/检索/技能变更跑固定12题：6正常（资料命中/改写/模板/Skill/工具/多轮），6负向（跨班/空库/无关/材料注入/工具注入/依赖故障）。 | 每题保留版本、输入、预期、实际及判定；12/12满足各自预期才通过。拒答题按应用spec或错误码判定，不凭“像是回答正确”。当前评测集尚待业务建立。 |
| 记录request_id、模型/提示词版本、耗时、用量（供应商缺失则unknown）与工具状态；普通日志不记密钥、学生原文或完整上下文。 | 抽查日志/响应/报告；敏感原文泄漏失败。需取证时显式启用脱敏记录，限定权限与留存期，不默认开启。 |
