## Decisions

1. 沿用docs/lesson-07/showcase.md作为唯一讲解稿，约6分钟，围绕做了什么/为什么/后续怎么做；不新建PPT或另一套长稿。
2. docs/roadmap.md作为仓库内唯一阶段规划：P0现有工程基线、P1认证与班级知识库、P2应用/模板/Skill/MCP问答、P3作业/复核/错题、P4学情与部署。每阶段含审核重点和完成证据，全部业务阶段标计划。
3. .agents/rules/review.md补课程核查项，引用docs/reviews/template.md；不重复制品/安全/数据条款，评审记录引用其依据。
4. 模板同一记录容纳七类对象、七维结果、逐文件三分结论和高风险“三件事”：查了什么、依据、结论。记录覆盖度用已实现/部分实现/未实现；待验证不能划为已通过。
5. 当前文档变更单独留自审记录，纯文档的事务/并发/运行性能为有理由的N/A，不伪造代码缺陷或人类交叉意见。单人项目的旧适配与课程新peer要求不等价；写明待教师确认，后续业务无独立评审不得宣称课程流程完整，CI不是替代。
6. 现有静态/历史/单元/漏洞/Compose验收为自动层；数据库查询专项、并发事务复核随业务增加并留证，不能因工具名存在声称整库审核完整。
