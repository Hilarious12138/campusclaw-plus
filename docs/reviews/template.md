# 变更审核记录模板

复制为`docs/reviews/YYYY-MM-DD-<change>.md`，一份记录覆盖该次变更。不要把空模板、未执行项或AI意见当成审核通过。

## 范围与依据

- 时间/时区、change、基线提交、受审提交或diff范围：待填。
- AI生成范围、审核者职责、涉及spec/Scenario及规范：待填。
- 结论：待审核；独立评审者交叉评审：未完成。

## 七类逐段核查

每行写发现/证据/结论；无此代码须写不适用理由，不能仅打勾。

| 对象 | 核查问题 | 记录 |
| --- | --- | --- |
| 接口入口 | 参数与资源归属是否校验？返回字段是否必要？ | 待填 |
| 业务逻辑 | 是否符合Scenario、状态及规范？ | 待填 |
| 数据库操作 | 多写事务、唯一约束与并发保障是否有效？ | 待填 |
| 公共函数 | 是否重复实现？失败是否被吞掉？ | 待填 |
| 错误处理 | 非法输入、故障、冲突是否有出口且无内部信息泄露？ | 待填 |
| 安全与隐私 | 输入、输出、秘密、归属与权限边界是否可靠？ | 待填 |
| 性能 | 循环查询、索引、分页、调用限额是否有风险？ | 待填 |

## 七维结论

| 维度 | 证据与结论 |
| --- | --- |
| 需求覆盖率 | 按Scenario记录已实现/部分实现/未实现，不凭空估百分比 |
| 与需求的一致性 | 对照状态、字段、数据设计 |
| 失败路径覆盖 | 输入、依赖故障、约束冲突及副作用 |
| 查询性能风险 | 循环/索引/分页；未查不得称无风险 |
| 重复代码比例 | 写实际重复块/范围，若量化说明分母和工具，不编百分比 |
| 漏洞风险 | 对照安全规范及扫描范围，未验证单列 |
| 高风险场景 | 并发、事务、一致性分别留记录；N/A必须说明原因 |

## 检查、交叉评审与准入

- 命令/环境/退出码、报告位置、受验提交：待填；未来步骤不要预填通过。
- 发现→修复→复验：待填；共性问题反馈到哪份规则：待填。
- 独立交叉评审人、意见及处理：未完成；AI或本人换职责不是独立评审者。
- 合入结论/阻断项：待填。未完成评审或证据不齐不能填评审流程已完成。
- 例外如有：原因、影响、替代检查、责任职责、补齐条件、批准来源；单人流程适配须教师确认，不能自己宣布等价。
